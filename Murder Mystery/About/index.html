About

This is a Murder Mystery Party game "maker". You can submit a request and it'll be routed to OpenAPI where an AI will make the game of your choice with as simple as: number of players you'd like, attributes for those players, theme(s) , and a desired game length.

Please simply ensure that you've properly changed the API key located on line 36 of ./Game/script.js to your personal API Key created at OpenAPI.com

Enjoy!
