# MurderMystery


### Uses OpenAI to create a narrative for a Murder Mystery Party. You get to either enter your own names, or have AI generate them. Then enter a description for the story, and AI shall generate the story for the narrator at the party.

#### Unfortunately OpenAPI is no longer free and requires a purchase. This means that in order to use this, you'd need to purchase your own resources via OpenAPI that'll align with your own API Key. It is relatively cheap and if you plan to use this once, you need not spend more than one dollar. Please ensure you place your API key in the proper location under ./MurderMystery/Game/script.js
